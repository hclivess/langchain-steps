A Build the index

A loader makes Documents, a text splitter cuts them, an embedding model turns the pieces into vectors, a vector store keeps them.

Add your own text
Nothing running. The split card shows a live preview of the selected document.
1

Load

A document loader (BaseLoader) turns each file into a Document: the text in page_content, where it came from in metadata.

2

Split

RecursiveCharacterTextSplitter cuts at blank lines first, then line ends, then spaces, until every piece fits chunk_size. Each chunk repeats the end of the one before (chunk_overlap).

3

Embed

The Embeddings model turns each chunk into a vector. Texts with similar content get similar vectors. Every tile below is one chunk's vector.

4

Store

One call embeds the chunks and keeps text, metadata and vector under a new id. This store lives in memory: it is rebuilt on every ingest.

store = InMemoryVectorStore(embeddings)
ids = store.add_documents(chunks)

B Run the chain

The chain is five components joined with |. Each one's output is the next one's input.

Event log what the chain itself reports

Each component emits a start event, stream events while it produces output, and an end event.

5

Embed the question

Inside retrieve: the question goes through the same embedding model as the chunks, so they can be compared. Sent to the page as a custom event.

6

Retrieve

The vector store returns the k chunks whose vectors point most nearly the same way as the question's (cosine similarity, 1 = same direction).

store.similarity_search_with_score_by_vector(vector, k)
7

Format the documents

A plain Python function, wrapped as a runnable: it numbers the chunks and joins them into one string, the context.

8

Prompt template

ChatPromptTemplate fills its {slots} with the context and the question and returns the messages for the model.

9

Chat model

The model reads the messages and writes the answer. It streams: each piece arrives as its own event while the model is still working.

10

Output parser

StrOutputParser takes the text out of the model's message object. What it returns is what the chain returns.
